1. Get a logfile to parse
2. input a rolling window in seconds to look for brute force login attempts (default 60)
3. input a threshold count of failed attempts to look for (default 5)
4. Load the log entries into the program
5. Read each line and parse the log entries that match these regex format strings: r"^(?P<timestamp>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) "
    r"sshd\[\d+\]: (?P<status>Accepted|Failed) password for "
    r"(?:invalid user )?(?P<user>\S+) from (?P<ip>\d{1,3}(?:\.\d{1,3}){3}) port \d+ ssh2$"
Skip log entries that don't match
6. For each match, add to a collection of dicts containing the "timestamp": datetime, "status": "Accepted"|"Failed",
    "user": str, "ip": str parsed information
7. Keep only the failed entries from the parsed list, group them by IP, and sort each IP's timestamps
8. For each IP, slide a window across its timestamps: for each attempt, check whether at least threshold failures fall within window seconds of it.
If so, flag the IP with those attempts and stop checking it
9. Return the collection of flagged IPs mapped to those timestamps
10. Use the returned flagged ip collection to print the results
